# apAudit Community

apAudit is a free WordPress activity-history plugin. It records selected account, content, plugin, theme and software-update events in a local database table. Administrators can review the history, export CSV and configure retention.

## Install

1. Download the community ZIP from [Releases](https://github.com/mikelawson68/apaudit-community/releases), upload it under Plugins > Add New and activate it.
2. Visit Tools > apAudit to review the history and retention settings.
3. Review the site's privacy notice and policies for the information the log contains.

Requires WordPress 6.4 or later and PHP 8.0 or later. The GitHub community edition does not include the store updater; check this repository for releases and back up before updating. WordPress.org review is not yet complete.

## Privacy and support

The log may include usernames, event details and IP addresses. WordPress privacy requests can export matching history and redact identifying fields while retaining the activity record. Process requests before deleting the associated WordPress account; apAudit cannot match the email afterward. Deactivation stops scheduled cleanup and leaves existing records on the site. See [readme.txt](readme.txt) for details.

For product information and assistance, visit [apAudit](https://artistprowp.com/apaudit/) or [artistpro support](https://artistprowp.com/support/).
